# Dataset Directory

Place the challenge dataset files in their respective folders:

### Training Data (`dataset/train/`):
- `train_source1.tsv`
- `train_source2.tsv`
- `train_source3.tsv`
- `train_ground_truth.tsv`

### Test Data (`dataset/test/`):
- `test_source1.tsv`
- `test_source2.tsv`
- `test_source3.tsv`

*Note: Large TSV files (>100MB) are ignored by Git.*
